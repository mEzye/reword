# Reword

Нативний десктопний застосунок для голосової диктовки з анімованою панеллю та глобальною комбінацією клавіш. Інтерфейс написаний на Rust і Slint; українське мовлення розпізнається локально або на власному сервері.

**Статус:** проєкт у розробці. `main` містить панель і налаштування; голосове розпізнавання розробляється в [`feature/voice-dictation`](https://github.com/mEzye/reword/tree/feature/voice-dictation). Опубліковані релізи можуть містити лише візуальний прототип.

## Можливості

- Запис, розпізнавання та поступове вставлення тексту під час утримання **Ctrl+Alt+H**.
- Локальна **Parakeet TDT 0.6B v3 UK** через нативний рушій transcribe.cpp.
- CPU, NVIDIA CUDA та автоматичний перехід на CPU при помилці GPU.
- Окремий сервер для кількох клієнтських комп'ютерів.
- Плавна анімація зі зміною напрямку без перезапуску; хвилі реагують на мікрофон.
- Готові й власні палітри, налаштування швидкості появи та зникнення.

Модель завантажується один раз і залишається в пам'яті. Мікрофон записує лише під час утримання клавіш. Для локального розпізнавання не потрібні платні API, Python або PyTorch.

## Швидкий старт на Windows

Потрібні Git, Rust із Cargo та C++ toolchain для Windows.

```powershell
git clone --branch feature/voice-dictation https://github.com/mEzye/reword.git
cd reword
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-speech.ps1
.\Reword.exe
```

Сценарій завантажує модель приблизно на 740 МБ і нативний рушій, перевіряє SHA-256 та зберігає файли в `models` і `speech-runtime`. Початковий режим — CPU. Після завантаження локальна диктовка не потребує інтернету.

## Керування

| Дія | Результат |
| --- | --- |
| Утримання **Ctrl+Alt+H** (початкова комбінація) | Запис мікрофона й введення підтверджених слів в активне поле |
| Відпускання клавіш | Завершення запису та дописування останнього фрагмента |
| Меню трея → **Налаштування…** | Диктування, гарячі клавіші, кольори й анімація |
| Меню трея → **Вийти з Reword** | Завершення програми |

Початкова комбінація — **Ctrl+Alt+H**; її можна змінити без перезапуску в розділі **Гарячі клавіші** налаштувань. На Windows текст вставляється в початкове активне вікно. Якщо фокус перейшов до іншого вікна, повний результат залишається в полі останнього транскрипту в **Налаштуваннях** для ручного копіювання. Для введення в консоль адміністратора Reword має працювати з таким самим рівнем прав. Максимальна тривалість одного запису — дві хвилини.

Українська модель працює короткими фрагментами: розпізнавання починається під час диктування, а не після завершення всього запису. Незавершені слова перевіряються повторно перед вставленням. Затримка залежить від обладнання; це не посимвольне розпізнавання без затримки.

## Налаштування

Файли створюються поруч із виконуваним файлом.

| Файл | Призначення |
| --- | --- |
| `palettes.ini` | Іменовані колірні схеми та початкова палітра |
| `colors.ini` | Активна схема та резервні кольори |
| `animation.ini` | Швидкість появи, зникнення та спільний коефіцієнт |
| `speech.ini` | Режим розпізнавання, обчислення та адреса сервера |
| `hotkeys.ini` | Комбінація клавіш для початку диктування |

Власна палітра зберігається через поля кольорів, назву та кнопку **Зберегти**. Повторне збереження з тією самою назвою оновлює схему. Початковий конфіг: [assets/palettes.ini](assets/palettes.ini).

## CUDA та сервер

Встановлення готового CUDA-рушія:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-speech.ps1 -Backend cuda
```

Запуск окремого CPU-сервера:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-speech-server.ps1 -Listen 0.0.0.0:8178 -Device cpu
```

Клієнти підключаються через адресу та ключ із `speech-server.token`. Модель на клієнтських комп'ютерах не потрібна; запити обробляються послідовно однією завантаженою моделлю.

CUDA потребує рушія для архітектури відповідної відеокарти. Для Maxwell `sm_50` передбачено сценарій `build-cuda-sm50.ps1`; сумісність власної збірки перевіряється запуском розпізнавання.

Докладні інструкції, конфігурація й HTTP-протокол: [SPEECH.md](https://github.com/mEzye/reword/blob/feature/voice-dictation/SPEECH.md).

## Збірка й перевірки

```sh
cargo build --locked --profile fast
cargo test --locked --profile fast
```

Профіль `fast` використовує інкрементальну компіляцію без LTO й оптимізовані залежності. `release` вмикає ThinLTO, `dev` призначений для налагодження.

На Windows `build.ps1` підтримує системний Rust або портативний toolchain у `D:\Tools` і копіює exe в корінь репозиторію. Доступні параметри `-ReleaseBuild` та `-DebugBuild`. Кеш компіляції зберігається в `target`, звіти часу — у `target/cargo-timings`.

## Платформи та обмеження

- **Windows** — основна платформа розробки. CPU-розпізнавання, серверний обмін і автоматичний перехід на CPU перевірені на аудіофайлах.
- **macOS і Linux X11** — використовуються бібліотеки для кількох платформ; пакування та поведінка застосунку потребують окремої перевірки.
- **Linux Wayland** — повної підтримки глобальних клавіш і позиціонування панелі немає.

Інтерфейс використовує GPU: Vulkan із запитом API 1.1 або запасний OpenGL 3.3. Розпізнавання працює в окремому процесі. Редактор виправлень і автозапуск поки не реалізовані.
