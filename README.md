# Reword

Reword перетворює українське мовлення на текст і вводить його в програму, у якій ви працюєте. Утримуйте Ctrl+Alt+H і диктуйте. Слова з'являються під час мовлення, а після відпускання клавіш Reword дописує останній фрагмент.

## Можливості

- Локальне диктування без інтернету після завантаження мовної моделі. Аудіо залишається на вашому комп'ютері.
- Розпізнавання на процесорі або з прискоренням на сумісній відеокарті NVIDIA.
- Підключення кількох комп'ютерів до одного сервера розпізнавання. Клієнтам не потрібно завантажувати модель.
- Можна змінити клавіші для диктування й оформлення панелі.

Для локального диктування не потрібні обліковий запис чи підписка.

## Встановлення

Reword доступний для Windows x64. Версій для macOS і Linux наразі немає.

Поточну версію з диктуванням потрібно зібрати з коду. Старі збірки на [сторінці релізів](https://github.com/mEzye/reword/releases) містять лише інтерфейс.

Для збірки потрібні Git, Rust із Cargo та компілятор C++ для Windows.

```powershell
git clone --branch feature/voice-dictation https://github.com/mEzye/reword.git
cd reword
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-speech.ps1
.\Reword.exe
```

Скрипт `setup-speech.ps1` завантажує мовну модель приблизно на 740 МБ і компоненти для розпізнавання. Це потрібно зробити один раз. Початковий режим використовує процесор.

## Диктування

1. Відкрийте програму й поставте курсор у поле, куди потрібно ввести текст.
2. Утримуйте Ctrl+Alt+H і говоріть.
3. Відпустіть клавіші, коли закінчите.

Reword записує мікрофон лише під час утримання клавіш. Розпізнавання має затримку, яка залежить від обладнання. Тривалість однієї диктовки обмежена десятьма хвилинами.

Якщо перейти до іншого вікна під час диктування, Reword припинить вводити текст. Повний результат можна скопіювати з поля "Останній результат" у налаштуваннях.

Щоб вводити текст у програму, запущену від адміністратора, запускайте Reword з такими самими правами.

## Налаштування

Натисніть на іконку Reword біля годинника й відкрийте "Налаштування".

- У розділі "Диктування" виберіть розпізнавання на цьому комп'ютері або підключення до сервера.
- У розділі "Гарячі клавіші" задайте свою комбінацію замість Ctrl+Alt+H. Перезапуск не потрібен.
- У розділі "Кольори" виберіть готову схему або натисніть на кольоровий квадратик, щоб відкрити вибір кольору. Власну схему можна зберегти під окремою назвою.
- У розділі "Анімація" змініть швидкість появи й зникнення панелі.

Інструкції для [налаштування NVIDIA та окремого сервера](https://github.com/mEzye/reword/blob/feature/voice-dictation/SPEECH.md).

## Для розробників

Застосунок написаний на Rust і Slint. `build.ps1` створює `Reword.exe` у корені проєкту. Для збірки з повною оптимізацією використовуйте параметр `-ReleaseBuild`.

```powershell
cargo test --locked --profile fast
```

Опис розпізнавання та серверного API міститься в [SPEECH.md](https://github.com/mEzye/reword/blob/feature/voice-dictation/SPEECH.md). Зміни залежностей описані у [vendor/REWORD-PATCHES.md](vendor/REWORD-PATCHES.md).
